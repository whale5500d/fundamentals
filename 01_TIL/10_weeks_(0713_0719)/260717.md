# 딥다이브

## 딥다이브 주제

1. 운영체제에서 User mode와 Kernel mode를 분리하는 이유를 설명하고, 일반 애플리케이션이 파일 입출력이나 네트워크 요청을 수행할 때 Kernel mode가 개입하는 과정을 서술하시오.

2. 리눅스에서 프로세스와 스레드가 실행 단위로 동작하는 방식을 설명하고, 두 개념이 메모리 공유, 실행 흐름, 자원 사용 측면에서 어떻게 다른지 비교하시오.

3. 운영체제의 스케줄링이 여러 프로세스와 스레드의 실행 순서를 결정하는 방식을 설명하고, CPU 점유 시간이 긴 작업과 짧은 작업이 동시에 존재할 때 스케줄링 정책에 따라 시스템 응답성이 어떻게 달라질 수 있는지 분석하시오.

4. 네트워크 모델에서 데이터가 애플리케이션 계층에서 물리 계층까지 전달되는 과정을 설명하고, 각 계층이 담당하는 역할이 분리되어 있기 때문에 네트워크 문제를 단계적으로 진단할 수 있는 이유를 서술하시오.

5. 네트워크에서 패킷 손실과 지연이 발생하는 원인을 트래픽 처리 방식 관점에서 설명하시오.
