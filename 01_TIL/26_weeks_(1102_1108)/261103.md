## 고급 RAG (질문지)

1. 전문 용어와 제품 코드가 많은 문서에서 벡터 검색만으로 충분한 검색 품질을 얻지 못하고 있습니다. 하이브리드 검색과 리랭킹을 어떻게 설계하고, 각 단계의 효과를 어떻게 검증하겠나요?
2. 여러 문서의 정보를 결합해야 답할 수 있는 질문을 처리하려면 RAG를 어떻게 설계하겠나요? 질의 분해, 질의 재작성, 반복 검색의 적용 기준과 검색 종료 조건을 설명해 주세요.
3. 검색된 문서는 적절해 보이지만 최종 답변의 정확도가 낮습니다. 검색 단계와 생성 단계를 분리해 평가하는 방법, 사용할 지표, 오류 원인을 확인하기 위한 실험을 제안해 주세요.
4. 사용자별 문서 접근 권한이 다른 RAG 시스템에서 정보 유출을 어떻게 방지하겠나요? 검색 시 권한 필터링, 캐시 격리, 검색 문서에 포함된 프롬프트 인젝션에 대한 대응을 함께 설명해 주세요.
5. 문서가 자주 갱신되는 대규모 RAG 서비스에서 답변 품질, 데이터 최신성, 응답 지연, 비용을 어떻게 균형 있게 관리하겠나요? 인덱스 갱신, 캐싱, 검색 결과 수와 컨텍스트 길이 조정, 근거 부족 시 응답 정책을 포함해 설명해 주세요.
