## 알고리즘 (답안지)

- 1. 분석 지표
  - 2.  ✅ 시간 복잡도와 공간 복잡도란 무엇이며 언제 사용되나요?
    - 시간 복잡도: 입력 크기(n)에 대한 기본 연산 실행 횟수의 증가율
    - 공간 복잡도: 입력 크기(n)에 대한 알고리즘이 추가로 사용되는 메모리의 증가율
    - 입력 크기 n에 대해 연산 횟수와 메모리 사용량의 증가율을 나타낸 지표다. 동일한 하드웨어에서 알고리즘을 비교하고, 입력 규모와 제약 조건에 맞는 알고리즘을 선택할 때 사용한다.
    - 예시 1: (알고리즘 선택) 정렬된 배열에서 값을 찾는다고 가정하고 최대 연산 횟수 n = 10^6으로 가정하면, 선형 탐색은 O(n)이므로 최대 10^6회 연산한다. 다만 이진 탐색은 O(logn)이므로 20회 연산으로 해결할 수 있다. 정렬된 데이터이므로 이진 탐색을 선택한다.
    - 예시 2: (입력 제한 기반 실현 가능성 검증) n = 10^5이고, 제한 시간이 1초라고 가정한다. 일반적으로 1초에 10^8회 연산을 처리한다. O(n^2)일 경우 10^10회이므로 초과한다. O(nlogn)은 약 1.7 \* 10^6회로 통과한다.
    - 예시 3: (시간과 공간의 상충 관계) 피보나치 수를 구한다고 가정하고, n = 40이라 가정한다. 단순 재귀는 시간 O(2^n)이고 공간 O(n)의 호출 스택이다. 메모이제이션은 시간 O(n)이고 공간 O(n) (캐시)이다. 따라서 공간 복잡도는 동일하고 시간 복잡도가 줄어드므로 메모이제이션을 선택한다.
    - 예시 4: 배열에서 합이 target인 두 수의 쌍을 찾는다고 가정한다. 이중 반복문 O(n^2)에서 해시 집합(hash set) 사용 시 O(n)이다. 공간 복잡도는 O(1)에서 O(n)이다. 메모리 여유가 있고 n이 크면 해시 집합을 선택한다.
    - 예시 5: 임베디드 장치처럼 메모리가 수 KB로 제한된다고 가정한다. O(n^2)의 시간복잡도를 유지한다. O(1)의 공간복잡도를 유지한다. 메모리가 병목이면 시간이 느려도 공간 복잡도가 낮은 방식을 선택한다.

- 3. 구체 알고리즘(해결 대상 문제와 자료구조)
  - 2.  그래프 대상 (정점과 간선)
    - 1. ✅ 그래프 탐색 알고리즘에 대해 설명해주세요.
      - 그래프 탐색은 정점(vertex)과 간선(edge)로 구성된 그래프에서 시작 정점으로부터 도달 가능한 모든 정점을 빠짐없이 방문하는 절차 알고리즘이다. 방문 순서를 결정하는 자료구조에 따라 큐를 사용하는 BFS, 스택 또는 재귀를 사용하는 DFS로 나뉘며, 두 방식 모두 시간 복잡도는 O(V+E)이다.
      - 연결 여부 판단, 최단 경로 탐색, 사이클 탐지, 연결 요소 개수 계산 등 연산에 사용된다.
      - 그래프 표현: 인접 리스트(adjacencylist)는 공간 O(V+E)이다. 인접 행렬(adjacency matrix)은 공간 O(V^2)이다.
      - BFS 예시: 최단 거리
      - DFS 예시: 섬의 개수, 백트래킹
  - 1.  배열 대상
    - 3. ✅ 이진 탐색 알고리즘을 설명해주세요.
      - 정렬된 배열에서 탐색 범위를 매 단계 절반으로 줄여 목표 값을 찾는 알고리즘이다. 중앙 원소와 목표 값을 비교해 한쪽 절반을 버리므로 시간 복잡도는 O(log n)이다. 정렬되어 있다는 전제 조건이 성립해야 사용할 수 있다.
      - 조건 불만족에서 만족으로 한 번만 바뀌는 단조성(monotonicity)이 있으면 파라메트릭 서치로 적용한다.
      - 최적값을 직접 구하는 최적화 문제(optimization problem)를 특정 값이 조건에 만족하는지 판단하는 결정 문제로 바꾸고, 이진 탐색으로 만족하는 경계값을 찾는 기법이다.
      - 예시: (나무 자르기) 절단기 높이 H를 정해 잘린 나무 길이의 합을 M 이상이 되는 최대 H 구하는 문제. 필요한 길이 M을 얻을 수 있는 절단기 최대 높이 H를 구한다. 높이 H로 잘랐을 때 얻는 길의 합이 M 이상인지 결정한다. H가 커질수록 얻는 길이는 줄어든다. 따라서 H가 작으면 만족, 커지면 불만족으로 한 번만 바뀐다. 탐색 대상이 배열이 아닌 높이 후보 값의 범위 [0, 나무 최대 높이]이다.

  - 7.  ✅ 분할 정복 알고리즘은 무엇이며 어떤 문제에 사용하나요?
