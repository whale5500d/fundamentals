## 자연어 처리(NLP) (답안지)

1. 토큰화(tokenization)
   - 1. 단어, 문자, 서브워드 기반 토큰화의 차이와 장단점은 무엇인가요? 특히 한국어를 토큰화할 때 어떤 어려움이 있나요?
     - 한 줄 결론: 토큰화는 어휘 크기와 시퀀스 길이의 트레이드오프이고, 서브워드가 둘을 절충하며, 한국어는 교착어라 단어 경계가 모호해 이 문제가 더 커집니다.
     - 토큰화란? 텍스트를 모델이 처리하는 단위(토큰)로 나누고 각 토큰을 정수 ID에 매핑하는 전처리입니다. 어휘 사전(vocab)을 먼저 정하고, 입력을 토큰 열로 바꾼 뒤 ID로 임베딩 테이블을 조회합니다.
     - 단어 기반이란? 공백이나 형태소 단위로 자르는 방식입니다. 의미 단위가 보존되고 시퀀스가 짧지만, vocab이 커지고 사전에 없는 단어(OOV)는 `<UNK>`로 처리되어 정보가 사라집니다.
     - 문자 기반이란? 문자 하나를 토큰으로 쓰는 방식입니다. vocab이 작고 OOV가 없지만, 시퀀스가 길어지고 토큰 하나가 담은 의미가 약해 장거리 의존을 학습하기 어렵습니다.
     - 서브워드란? 자주 나오는 문자열 조각을 토큰으로 쓰는 중간 방식입니다. BPE는 가장 빈번한 인접 쌍을 반복 병합해 vocab을 만들고(WordPiece는 병합 기준이 우도 기반 (미검증)), 희귀 단어는 조각으로 쪼개 OOV를 피합니다.
     - OOV란? 학습 때 만든 vocab에 없는 토큰입니다. 단어 기반은 `<UNK>`로 뭉개지지만, 서브워드·문자 기반은 더 작은 조각으로 분해해 표현할 수 있습니다.
     - 한국어의 어려움이란? 교착어라 어근에 조사·어미가 붙어 같은 말이 "먹는/먹었다/먹고"처럼 여러 형태가 됩니다. 어절 단위는 vocab이 폭증하고, 형태소 분석기는 띄어쓰기·분석 오류가 뒤로 전파되며, 서브워드는 한글 조합이 많아 영어보다 토큰 수가 늘 수 있습니다 (미검증).

2. 텍스트 표현(representation)
   - 2. Bag-of-Words와 TF-IDF는 텍스트를 어떻게 벡터로 표현하나요? 두 방식이 문맥과 의미를 표현하는 데 갖는 한계는 무엇인가요?
     - 한 줄 결론: 둘 다 어휘 크기 차원의 희소 벡터를 만드는 빈도 기반 표현이라, 단어 순서와 의미 유사도를 담지 못합니다.
     - BoW란? 문서를 어휘 사전 차원의 벡터로 바꾸는 방식입니다. 각 차원은 해당 단어의 등장 횟수이고, 순서는 버리고 개수만 셉니다.
     - TF란? 한 문서 안에서 단어가 등장한 빈도입니다. 같은 문서에서 자주 나올수록 그 문서를 대표하는 단어로 봅니다.
     - IDF란? 단어가 코퍼스의 여러 문서에 얼마나 흔한지를 뒤집은 값에 로그를 취한 것입니다(대표식 `log(N/df)`, 변형이 여럿 (미검증)). 어디에나 나오는 단어는 낮은 가중치, 특정 문서에 몰린 단어는 높은 가중치를 받습니다.
     - TF-IDF란? TF와 IDF를 곱한 값입니다. 문서 안에서는 자주 나오지만 코퍼스 전체에서는 드문 단어를 강조해 문서를 구별합니다.
     - 희소성이란? 대부분의 차원이 0인 고차원 벡터라는 성질입니다. 어휘가 커질수록 차원이 같이 커져 메모리와 연산 부담이 늘고, 벡터 간 거리가 의미 있게 구분되지 않습니다.
     - 한계란? 순서를 무시해 "개가 사람을 문다"와 "사람이 개를 문다"가 같은 벡터가 됩니다. 단어마다 독립된 차원이라 "자동차"와 "차"도 서로 직교하고, 동의어와 다의어를 구분하지 못합니다. TF-IDF는 단어 중요도는 반영하지만 문맥과 의미는 반영하지 않습니다.
   - 3. Word2Vec과 같은 정적 임베딩과 문맥 기반 임베딩은 어떻게 다른가요? 다의어를 처리하는 방식을 중심으로 설명해주세요.
     - 한 줄 결론: 정적 임베딩은 단어당 벡터가 하나라 다의어가 한 벡터에 섞이고, 문맥 임베딩은 같은 단어도 주변 문맥에 따라 다른 벡터를 만듭니다.
     - 분포 가설이란? 비슷한 문맥에 나오는 단어는 비슷한 의미를 갖는다는 가정입니다. 임베딩 학습은 이 가정으로 의미를 벡터 거리에 반영합니다.
     - Word2Vec이란? 주변 단어 예측 과제로 단어 벡터를 학습하는 방법입니다. Skip-gram은 중심 단어에서 주변을, CBOW는 주변에서 중심 단어를 예측하고, 학습이 끝나면 단어마다 고정된 벡터를 담은 룩업 테이블이 남습니다.
     - 정적 임베딩의 다의어 한계란? 단어 하나에 벡터 하나라서, "bank"의 은행과 강둑 의미가 한 벡터에 섞입니다. 어떤 문장에 나오든 벡터가 변하지 않습니다.
     - 문맥 임베딩이란? 문장 전체를 모델에 통과시킨 은닉 상태를 단어의 벡터로 쓰는 방식입니다. ELMo는 양방향 LSTM, BERT는 트랜스포머 인코더를 쓰며, 같은 단어도 문장마다 다른 벡터가 되어 다의어가 구분됩니다.
     - 차이의 핵심이란? 정적 임베딩은 단어 → 벡터의 룩업이고, 문맥 임베딩은 문장 전체를 입력으로 받는 함수의 출력입니다. 그래서 문맥 임베딩은 입력마다 모델 추론이 필요해 비용이 더 듭니다.

3. 언어 모델링(language modeling)
   - 4. 언어 모델이 학습하는 확률은 무엇인가요? 자기회귀 언어 모델링과 마스크 언어 모델링의 학습 목표를 비교해주세요.
     - 한 줄 결론: 언어 모델은 토큰열의 확률을 학습하고, 자기회귀는 앞 토큰으로 다음 토큰을, 마스크 언어 모델링은 양쪽 문맥으로 가려진 토큰을 맞추도록 학습합니다.
     - 언어 모델이란? 토큰열 `w1..wn`의 결합 확률 `P(w1..wn)`을 모델링하는 모델입니다. 어떤 문장이 얼마나 자연스러운지를 확률로 표현합니다.
     - 연쇄 법칙이란? 결합 확률을 조건부 확률의 곱 `P = ∏ P(w_t | w_<t)`으로 쪼개는 규칙입니다. 이 분해 덕분에 "앞 토큰이 주어졌을 때 다음 토큰의 분포"를 학습 대상으로 삼을 수 있습니다.
     - 자기회귀(AR) 언어 모델링이란? 왼쪽 문맥만 보고 다음 토큰을 예측하며 교차 엔트로피를 최소화합니다. 미래 토큰을 못 보게 인과 마스크를 쓰고, 한 번에 한 토큰씩 생성하는 방식과 일치합니다(GPT 계열).
     - 마스크 언어 모델링(MLM)이란? 입력의 일부(BERT는 약 15% (미검증))를 `[MASK]`로 가리고, 양쪽 문맥으로 원래 토큰을 복원합니다. 학습하는 것은 `P(가려진 토큰 | 나머지)`이고, 이는 결합 확률의 곱으로 분해되지 않습니다.
     - 두 방식의 비교란? AR은 모든 위치가 학습 신호이고 생성에 바로 쓰이지만 오른쪽 문맥을 못 봅니다. MLM은 양방향 문맥을 써서 이해 과제에 유리하지만, 가린 위치만 학습 신호가 되고 `[MASK]`가 추론 때는 없다는 불일치가 있어 생성에는 직접 쓰기 어렵습니다.

4. 평가(evaluation)
   - 5. 정확도, 정밀도, 재현율, F1 점수는 각각 어떤 상황에서 유용한가요? 클래스가 불균형한 데이터에서 macro-F1과 micro-F1은 어떻게 다르게 해석해야 하나요?
     - 한 줄 결론: 지표는 어떤 오류가 더 비싼지에 따라 고르고, 불균형 데이터에서는 정확도 대신 클래스별 지표와 macro/micro 선택이 핵심입니다.
     - 혼동행렬이란? 예측과 정답을 TP, FP, FN, TN으로 나눈 표입니다. 모든 지표가 이 네 칸의 조합으로 계산됩니다.
     - 정확도(accuracy)란? 전체 중 맞힌 비율 `(TP+TN)/전체`입니다. 클래스가 균형일 때 유용하지만, 95:5 데이터에서 전부 다수 클래스로 찍어도 95%가 나와 불균형에서는 속기 쉽습니다.
     - 정밀도와 재현율이란? 정밀도는 양성이라 예측한 것 중 진짜 양성의 비율 `TP/(TP+FP)`, 재현율은 진짜 양성 중 찾아낸 비율 `TP/(TP+FN)`입니다. 오탐(FP)이 비싼 스팸 필터는 정밀도를, 미탐(FN)이 비싼 질병 진단이나 사기 탐지는 재현율을 봅니다.
     - F1이란? 정밀도와 재현율의 조화평균 `2PR/(P+R)`입니다. 조화평균은 낮은 쪽에 끌려가기 때문에 둘 중 하나만 높아서는 점수가 오르지 않아, 두 지표의 균형이 필요한 불균형 데이터에서 씁니다.
     - macro-F1이란? 클래스별 F1을 먼저 구한 뒤 단순 평균합니다. 클래스 크기와 무관하게 동등하게 반영해 소수 클래스 성능이 나쁘면 점수가 떨어지므로, 소수 클래스 성능을 보고 싶을 때 씁니다.
     - micro-F1이란? 모든 클래스의 TP, FP, FN을 합산한 뒤 한 번 계산합니다. 샘플 수가 많은 클래스가 결과를 지배해 다수 클래스 성능을 반영하며, 단일 라벨 다중분류에서는 정확도와 같아집니다.
