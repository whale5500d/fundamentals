## 딥다이브 주제

1. FP32, FP16, INT8, INT4가 LLM 추론에서 연산 정밀도, 메모리 사용량, 추론 속도, 응답 품질에 어떤 차이를 만드는지 설명하시오. 
2. LLM Quantization에서 Zero-point와 Scale factor가 부동소수점 가중치를 정수 표현으로 변환하는 과정을 설명하고, 양자화 오차가 모델 출력 품질에 미치는 영향을 서술하시오. 
3. Post-Training Quantization(PTQ)이 기존에 학습된 LLM을 다시 전체 학습하지 않고 경량화하는 방식을 설명하고, PTQ 적용 시 모델 성능 저하가 발생할 수 있는 원인을 분석하시오. 
4. GGUF Format이 Llama.cpp 기반 로컬 LLM 추론 환경에서 사용되는 이유를 설명하고, 모델 파일 구조와 실행 환경 최적화 관점에서 GGUF가 제공하는 장점을 서술하시오. 
5. QLoRA가 양자화된 LLM 위에서 LoRA Adapter를 학습하는 구조를 설명하고, 전체 파인튜닝 대비 학습 메모리와 비용을 줄일 수 있는 원리를 분석하시오.
6. QLoRA에서 도입된 NF4(4-bit NormalFloat) 데이터 타입과 이중 양자화(Double Quantization)가 일반 INT4 양자화 및 LoRA 대비 추가적인 학습 VRAM을 줄일 수 있는 원리를 분석하시오.

### 선정된 주제

- 주제: QLoRA에서 도입된 NF4(4-bit NormalFloat) 데이터 타입과 이중 양자화(Double Quantization)가 일반 INT4 양자화 및 LoRA 대비 추가적인 학습 VRAM을 줄일 수 있는 원리를 분석하시오.
