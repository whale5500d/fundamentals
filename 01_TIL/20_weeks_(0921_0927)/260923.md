### DL (답안지)

1. 구조
   - 2. ✅ 합성곱 계층이 완전 연결 계층 대비 갖는 장점을 파라미터 공유(parameter sharing)와 지역 연결성(local connectivity) 관점에서 설명해 주세요.
     - 슬라이딩: 필터(커널)를 입력 위에서 정해진 간격(stride)만큼씩 이동시키며, 매 위치마다 합성곱 연산을 반복 수행하는 과정. 한 번 이동할 때마다 필터가 겹치는 입력의 국소 영역과 필터 가중치 간의 연산 결과가 출력 특징맵의 한 값이 됨.
     - 합성곱 계층: 입력에 작은 크기의 필터(커널)를 슬라이딩시키며 합성곱 연산을 수행해 특징맵(feature map)을 생성하는 신경망 계층. 각 뉴런이 입력 전체가 아닌 국소 영역(local connectivity)에만 연결되고, 하나의 필터가 모든 위치에서 동일한 가중치를 공유(parameter sharing)하는 구조를 가짐.
     - 완전 연결 계층: 이전 계층의 모든 뉴런이 다음 계층의 모든 뉴런과 하나씩 전부 연결된 신경망 계층. 각 연결마다 독립적인 가중치를 가지며, 공간적 위치 정보나 지역성을 구조적으로 반영하지 않음
     - 파라미터 공유: 하나의 필터(커널)가 갖는 가중치 집합을 입력의 모든 위치에서 동일하게 재사용하는 것. 위치마다 별도의 가중치를 학습하지 않고, 같은 필터를 슬라이딩하며 적용함.
     - 지역 연결성: 하나의 뉴런이 입력 전체가 아니라 국소 영역(local region)에만 연결되는 구조. 완전연결 계층처럼 모든 입력 픽셀과 연결되는 대신, 커널 크기만큼의 인접한 영역에만 연결됨.
     - 완전 연결 계층은 모든 입력 뉴런이 모든 출력 뉴런과 연결됩니다. 국소 영역이 존재하지 않기 때문에 지역 연결성은 없습니다. 또한, 연결마다 독립적인 가중치를 갖기 때문에, 같은 가중치를 재사용하는 구조도 없습니다. 반대로 합성곱 계층은 하나의 뉴런(필터)이 입력의 국소 영역에만 연결됩니다. 또한 하나의 필터가 모든 위치에서 동일한 가중치를 재사용합니다.
   - 3. ✅ 입력 크기, 커널 크기, 스트라이드(stride), 패딩(padding)이 주어졌을 때 출력 특징맵의 크기를 계산하는 식을 설명하고, 32×32 입력에 5×5 커널, 스트라이드 1, 패딩 0을 적용한 결과를 구해 보세요.
     - 스트라이드: 합성곱 연산 시 커널이 슬라이딩하며 한 번에 이동하는 간격, 값이 클수록 출력 특징맵의 크기가 작아짐.
     - 패딩: 입력의 가장자리에 추가 값(통상 0, zero-padding)을 덧붙이는 것. 커널이 슬라이딩할 수 있는 유효 입력 크기를 늘려서 출력 특징맵의 크기를 조정하거나 입력과 출력의 공간 크기를 동일하게 유지하는 데 사용.
     - 출력 특징맵의 크기: (입력 크기 - 커널 크기 + 패딩 크기 \*2) / 스트라이드 + 1
     - 적용 결과: (32 - 5 + 0\*2) / 1 + 1 = 28
2. 손실함수
   - 9. ✅ 분류 문제에서는 왜 MSE 대신 크로스 엔트로피(cross-entropy)를 손실 함수로 쓰나요? 확률의 관점에서 크로스 엔트로피를 최소화한다는 것이 어떤 의미인지 설명해 주세요.
     - 손실함수: 모델의 예측값과 실제값의 차이를 하나의 스칼라로 정량화하는 함수를 의미함. 이 값이 클수록 예측이 나쁘고, 학습 과정으로 최소화하는 방향으로 파라미털르 조정.
     - 분류 문제: 미리 정의된 이산적 범주 중 하나로 할당하는 문제. 출력이 연속값이 회귀 문제와 대비되며, 클래스 레이블로 주어짐.
     - MSE: 평균제곱오차, 예측값과 실제값의 차이를 제곱한 뒤 평균한 손실함수. 주로 회귀 문제에서 사용됨.
     - 크로스 엔트로피: 두 확률분포 간의 차이를 측정하는 손실함수. 분류 문제에서 정답 레이블(원-핫 벡터)과 모델이 출력한 확률분포 간의 차이를 측정하는 데 사용.
     - 우도(likelihood)
     - 최대우도추정(MLE)
