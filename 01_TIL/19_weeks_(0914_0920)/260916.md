# 월

## 모의면접 질문

### 둘째날 - 웹

- 1. HTTP로 통신하는 것과 HTTPS로 통신하는 것은 실제로 어떤 차이가 있나요? 그리고 로그인이나 결제 같은 서비스에서는 왜 HTTPS를 사용해야 할까요?
- 2. HTTPS를 사용하면 데이터가 암호화된다고 하는데, 단순히 데이터를 암호화하는 것 외에 어떤 보안 효과가 있나요?
- 3. FastAPI에서 사용자가 보내는 데이터가 우리가 기대한 형식과 다르다면 어떻게 처리할 수 있을까요? Pydantic을 사용하면 어떤 점이 편리한가요?
- 4. AI 모델을 API로 서비스한다고 했을 때, 사용자가 잘못된 형식이나 비정상적인 값을 보내는 것을 왜 미리 검증하는 것이 중요할까요?
- 5. API를 운영하다 보면 잘못된 요청뿐만 아니라 서버 오류나 AI 모델의 예측 실패도 발생할 수 있습니다. 이런 상황에서 사용자에게는 어떤 식으로 오류를 알려주는 것이 좋을까요?
- 6. FastAPI에서 예외가 발생했을 때 기본적인 예외 처리만 사용하는 것과 직접 예외를 정의해서 처리하는 것에는 어떤 차이가 있을까요?
- 7. AI 모델을 호출하는 API를 만들었는데 요청이 동시에 아주 많이 들어온다면, 일반적인 동기 방식으로 처리할 때 어떤 문제가 생길 수 있을까요?
- 8. FastAPI의 async와 await를 사용하면 여러 요청을 효율적으로 처리할 수 있다고 하는데, 이것이 모든 상황에서 더 빠르다는 의미일까요?
- 9. AI 모델 추론 API에서 비동기 처리가 특히 유용한 상황과 오히려 큰 도움이 되지 않는 상황을 각각 예로 들어 설명해 주실 수 있을까요?
- 10. 사용자가 AI 모델에 요청을 보내고 결과를 받는 서비스를 직접 만든다고 한다면, 입력 검증부터 모델 추론, 오류 처리, 응답 반환까지 어떤 부분들을 고려해서 설계하시겠어요?
