# 정렬

## 정의

- 정렬된 배열에서 탐색 범위를 절반씩 좁혀가며 목표값을 찾는 탐색 알고리즘
- 매 단계마다 중간값(mid)과 목표값을 비교해, 목표값이 중간값보다 크면 오른쪽 절반을, 작으면 왼쪽 절반을 탐색 범위로 선택한다.
- 시간복잡도는 O(logN)이며, 선형 탐색(O(N)) 대비 정렬이라는 전제 조건을 활용해 효율을 확보한다.

핵심 조건

1. 정렬 상태: 배열이 오름차순 또는 내림차순으로 정렬되어 있어야 한다.
2. 단조성(monotonicity): 탐색 대상이 "조건을 만족하는 지점"을 기준으로 한쪽은 모두 참, 다른 한쪽은 모두 거짓으로 나뉘는 성질을 가져야 한다. 값 자체의 정렬뿐 아니라, 조건 함수의 단조성도 이진 탐색 적용 여부를 결정한다.
3. 랜덤 접근(random access) 가능한 자료구조: 배열처럼 인덱스로 O(1) 접근이 가능해야 중간값 탐색이 효율적이다(연결 리스트에서는 이진 탐색의 이점이 사라짐).

## 대표 문제 유형

1. 값 탐색(exact value search): 정렬된 배열에서 특정 값의 존재 여부/인덱스를 찾는 기본형.
2. 경계값 탐색(lower bound / upper bound): 특정 값 이상(또는 이하)이 처음 나타는 위치를 찾는 변형. 중복값이 있는 배열에서 필요.
3. 매개변수 탐색(parametric search): 값 자체가 "조건을 만족하는 최솟값/최댓값"을 탐색 대상으로 삼는 유형. 정렬된 배열이 아니라 "답의 후보 범위"에 이진 탐색을 적용한다. (예: 최소 시간, 최대 개수 등을 구하는 문제)
4. 회전된 배열 탐색(rotated sorted array): 정렬되어 있으나 특정 지점에서 순환 이동된 배열에서 탐색하는 변형.

## 유형 구분 기준

- 배열 인덱스 자체를 탐색(1, 2, 4번): 데이터가 이미 정렬되어 있고, 그 배열 위에서 직접 이진 탐색.
- 정답의 후보 범위를 탐색(3번): 데이터 자체는 정렬되어 있지 않을 수 있으나, **답이 될 수 있는 값의 범위가 단조성을 가질 때** 그 범위에 이진 탐색을 적용.
