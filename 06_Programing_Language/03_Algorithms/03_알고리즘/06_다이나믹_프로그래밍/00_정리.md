동적 계획법 (DP, dynamic programming) 개념 정리:

**정의**: 큰 문제를 겹치는 작은 부분문제 (overlapping subproblem)로 나누고, 각 부분문제의 답을 한 번만 계산해 저장한 뒤 재사용해 전체 답을 구하는 기법이다. 앞에서 배운 그리디가 선택을 번복하지 않고 확정하는 반면, DP는 가능한 선택을 모두 비교하되 중복 계산을 제거한다. 동전 교환에서 `[400, 300, 1]` 반례가 그리디로 풀리지 않았던 이유가 여기에 해당하며, DP가 그 해결책이다.

**핵심 조건**:

1. 최적 부분 구조 (optimal substructure): 부분문제의 최적해로 전체 문제의 최적해를 구성할 수 있어야 한다. 그리디에서 배운 개념과 같다.
2. 중복되는 부분문제 (overlapping subproblem): 같은 부분문제가 반복해서 등장해야 저장의 이점이 생긴다. 중복이 없으면 분할 정복 (divide and conquer)이다. 병합 정렬이 이 경우다.
3. 상태 정의 (state definition): `dp[i]`가 무엇을 의미하는지 명확히 정의해야 한다. DP 풀이의 핵심이다.
4. 점화식 (recurrence relation): 현재 상태를 이전 상태로 표현하는 식이다. 예: `dp[i] = dp[i-1] + dp[i-2]`.
5. 초기값 (base case): 점화식이 시작되는 가장 작은 상태의 값이다.
6. 계산 순서: 점화식이 참조하는 상태가 먼저 계산되어 있어야 한다.

**구현 방식 두 가지**:

- 탑다운 (top-down, 메모이제이션 memoization): 재귀로 큰 문제부터 풀고, 계산한 결과를 저장해 재사용한다. 앞에서 배운 DFS의 재귀와 연결된다.
- 바텀업 (bottom-up, 타뷸레이션 tabulation): 작은 문제부터 반복문으로 표를 채워 올라간다. 앞에서 배운 플로이드-워셜이 바텀업 DP다.

**표 1: 그리디, 분할 정복, DP 비교**
| 구분 | 그리디 | 분할 정복 | DP |
|---|---|---|---|
| 선택 번복 | 불가 | 해당 없음 | 모든 선택 비교 |
| 부분문제 중복 | 해당 없음 | 없음 | 있음 |
| 결과 저장 | 안 함 | 안 함 | 저장 후 재사용 |
| 대표 문제 | 구간 스케줄링 | 병합 정렬 | 동전 교환(일반) |

**대표 문제 유형**:

1. 1차원 DP: 상태가 `dp[i]` 하나의 인덱스로 표현된다. 피보나치 수열, 계단 오르기, 타일링.
2. 2차원 DP: 상태가 `dp[i][j]` 두 인덱스로 표현된다. 격자 경로 개수, 최소 비용 경로.
3. 배낭 문제 (knapsack): 용량 제한 안에서 가치를 최대화한다. 0/1 배낭이 대표이며, 그리디의 분할 가능 배낭과 구분된다.
4. 최장 증가 부분 수열 (LIS, longest increasing subsequence).
5. 최장 공통 부분 수열 (LCS, longest common subsequence)과 편집 거리 (edit distance): 두 문자열 비교 유형이다.
6. 동전 교환 (일반): 그리디가 실패한 `[400, 300, 1]` 유형을 해결한다.
7. 구간 DP, 비트마스크 DP, 트리 DP: 상태 정의가 복잡해 후순위를 권장한다.

**유형 구분 기준**: 배열은 "조작 방식", 그리디는 "최적화 대상의 구조", 그래프는 "구하는 값과 입력 형태"가 기준이었다. DP는 "상태 정의의 차원과 형태"가 기준이다.

**표 2: 유형 구분 기준**

| 상태 형태            | 유형          | 예시                  |
| -------------------- | ------------- | --------------------- |
| 인덱스 1개           | 1차원 DP      | 피보나치, 계단 오르기 |
| 인덱스 2개 (위치)    | 2차원 격자 DP | 격자 경로             |
| 인덱스 + 용량/금액   | 배낭형 DP     | 0/1 배낭, 동전 교환   |
| 인덱스 2개 (두 수열) | 수열 비교 DP  | LCS, 편집 거리        |

**DP 적용 판단 단서**: 앞에서 정리한 "제약조건에서 패턴을 역추론"하는 방식과 같다.

- 최댓값, 최솟값, 경우의 수를 구하는 문제이면서 그리디의 반례가 존재한다.
- N이 작아 완전 탐색은 지수 시간이지만, 상태 수(예: N×M)는 다항 시간이다.
- 완전 탐색 재귀 트리에서 같은 인자 조합이 반복 호출된다.

**제외 항목**: 구간 DP, 비트마스크 DP, 트리 DP는 선행 개념이 많아 후순위로 둔다.

**권장 순서**: 1차원 DP(피보나치) → 계단 오르기 → 동전 교환(일반) → 격자 경로(2차원) → 0/1 배낭 → LIS → LCS. 피보나치로 "중복 계산이 어떻게 발생하고 저장으로 어떻게 제거되는가"를 먼저 체감하는 것이 순서상 합당하다.
