# 정렬

## 정의

- "데이터를 특정 순서(오름차순/내림차순)로 재배열"하는 알고리즘
- 비교 기반(comparison-based)과 비비교 기반(non-comparison-based)으로 구분

핵심 조건

1. 시간복잡도: 최선/평균/최악 케이스에서 비교·교환 횟수
2. 공간복잡도: 추가 메모리 사용 여부(제자리 정렬, in-place 여부)
3. 안정성(stability): 값이 같은 두 요소의 상대적 순서가 정렬 후에도 유지되는가

## 대표 문제 유형

1. 버블 정렬(bubble sort): 인접 요소 비교·교환 반복. O(N^2), 안정적(stable)
2. ⭐️ 선택 정렬 (selection sort): 매 단계 최솟값을 찾아 앞으로 이동. O(N²), 불안정(unstable).
3. ⭐️ 삽입 정렬 (insertion sort): 이미 정렬된 부분에 새 요소를 적절한 위치에 삽입. O(N²), 안정적. 앞서 배열 항목에서 다룬 정렬 삽입과 동일한 원리다.
4. 병합 정렬 (merge sort): 분할 정복(divide and conquer)으로 절반씩 나눠 정렬 후 병합. O(N log N), 안정적, 추가 공간 O(N) 필요.
5. ⭐️ 퀵 정렬 (quick sort): 기준값(pivot) 기준으로 분할 후 재귀 정렬. 평균 O(N log N), 최악 O(N²), 불안정, 제자리 정렬 가능.
6. ⭐️ 계수 정렬 (counting sort) / 기수 정렬 (radix sort): 값의 범위가 제한적일 때 비교 없이 카운팅으로 정렬. O(N+K), 특정 조건(정수, 범위 제한)에서만 사용 가능.

## 유형 구분 기준

"분할 전략과 비교 방식"이 기준이다.

- 단순 반복 비교형(버블, 선택, 삽입): 구현이 간단하니 O(N^2)
- 분할 정복형(병합, 퀵): O(NlogN)으로 효율적이나 구현 복잡도 상승
- 비교 회피형(계수, 기수): 값의 범위 제약이 있을 떄만 적용 가능하나 O(N)에 가까운 성능
