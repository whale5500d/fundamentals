# 코딩테스트 준비

- 제약조건(constraint): 문제가 명시된 입력 크기 범위, 시간 제한, 메모리 제한, 값의 범위 등 풀이 방식을 제한하는 조건
- 제약조건에 따라 패턴이 달라진다.
  - 입력 크기와 시간복잡도(time complexity) 제한을 역산하면 사용 가능한 패턴이 좁혀진다.
  - 예시
    - 시간 제한 1초에 N <= 10^5일 경우, O(N logN) 이하 알고리즘(이분탐색, 정렬 기반)만 허용된다.
    - O(N^2)인 완전탐색은 제외된다.
    - N <= 20 수준으로 작으면 O(2^N)인 백트래킹/완전탐색도 허용범위에 들어간다.
